# Smash Padel Focșani – Site prezentare

Site de prezentare pentru clubul de padel **Smash Padel Focșani** (Bd. București nr. 16A, Focșani, Vrancea).

## Rulare locală

```bash
npm install
npm run dev
```

Deschide [http://localhost:3000](http://localhost:3000).

## Build producție

```bash
npm run build
npm start
```
